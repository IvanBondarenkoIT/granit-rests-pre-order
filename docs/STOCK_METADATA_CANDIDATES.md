# Кандидаты таблиц/процедур по RDB$DESCRIPTION

- Таблиц/представлений: **77**
- Полей: **552**
- Процедур: **129**
- Таблиц с GDSKEY/QUANT/QNT: **48**

## Приоритетные таблицы (остат / склад / движен)

- **CRDS_DGVDT** (view): Таблица расходных документов карточек
- **CRDS_DGVKT** (view): Таблица приходных документов карточек
- **CURRSTOR** (view): Движение валюты - операции по валютным счетам
- **CURRSTORDAYS** (view): Движение валюты - остатки по валютным р/с по дням
- **CURRSTORDAYSACCR** (view): Движение валюты - привязка проводок
- **DGVDT** (view): Счета Дебиторов (счета / расходные накладные на складе)
- **DGVKT** (view): Счета Кредиторов (приходные накладные на складе)
- **DGVWKG** (view): Производство: накладные на выпуск изделий в производстве - оприходование изделий на складе готовой продукции - списание материалов и комплектующих из производства
- **DK_DISCOUNTBONUSSETSTORGRP** (view): Связи с группами складов для наборов скидок и бонусов
- **DK_GIFTCERTIFICATE** (view): Движения подарочных сертификатов
- **DOCMTASKFINANCE** (view): Расходы по задачам (документооборот)
- **GDDDT** (view): Позиции товаров в расходных счетах / накладных
- **GDDDTDDU** (view): Услуги в расходных накладных (по складу)
- **GDDKT** (view): Позиции товаров в приходных накладных
- **GDDKTDDU** (view): Услуги в приходных накладных
- **GDDKTPARAM** (view): Параметры - приход товара (серийные номера)
- **GDDKTQNT** (view): Позиции товара в остатке на складах (для быстрого просмотра товара в наличии)
- **HBGDDDU** (view): Виды услуг в расходных накладных (реализация товара)
- **KASSDATA** (view): Приходные и расходные кассовые ордера Приходные - SUMMA > 0 Расходные - SUMMA < 0
- **MBPDGV** (view): Накладные по движению МБП
- **SALE** (view): Платежные Документы - приход (Дебиторы)
- **SALEKTCR** (view): Привязка Кредиторских Оплат к Счетам Кредиторов (Приходным Накладным)
- **STORGRP** (view): Группы Складов
- **STORGRPREF** (view): Входимость Складов в Группы (STORGRP)
- **STORLIST** (view): Справочник Складов
- **SZDTCR** (view): Распределение оплат по складским заказам (реализация товара)
- **USERSTOR** (view): Доступ Пользователей к Складам
- **WORKCALCMST** (view): Расчетная Ведомость распределения накладных расходов
- **WORKCALCNK** (view): Виды накладных расходов в Ведомости
- **WORKCALCNKPRM** (view): Привязка распределяемых накладных расходов к параметрам по товарам (изделиям)
- **WORKCALCPODR** (view): Цеха в ведомости распределения накл. расходов
- **WORKCALCPROV** (view): Привязка проводок по распределению накладных расходов
- **WORKHBNK** (view): Накладные Расходы (справочник)
- **WORKNKDG** (view): Привязка накладных расходов к накладным на оприходование изделий из производства
- **WORKPLANSTOR** (view): Анализ выпуска изделий - привязка складов к ведомости
- **WORKZNK** (view): Накладные расходы в заказе

## Процедуры (остат / движен)

- **CURRSTORDAYS_GENACCNREC**: Формирование проводок - движение валюты.
- **GDDDT_MOVEGOODS**: Форма учета движения товара (по указанному складу). Входные параметры: BDATE - дата начала периода EDATE - дата окончания периода STOR - склад (поле ID таблицы STORLIST) Выходные параметры: KID INTEGE
- **GDDDT_MOVEGOODSALL**: Форма учета движения товара (по всем складам)
- **GDDDT_MOVEGOODSGRP**: Форма учета движения товара (по указанному складу и группе товара). Выдает весь ассортимент товара по указанной группе. Результат требует группировки с суммированием. Входные параметры: BDATE - дата н
- **GDDDT_MOVEGOODSONE**: Форма учета движения товара (по указанному складу и товару). Входные параметры: BDATE - дата начала периода EDATE - дата окончания периода STOR - склад (поле ID таблицы STORLIST) GDSID - товар Выходны
- **GDDDT_MOVEGOODS_GRP**: Форма учета движения товара (по указанному складу). Входные параметры: BDATE - дата начала периода EDATE - дата окончания периода STOR - склад (поле ID таблицы STORLIST) Выходные параметры: KID INTEGE
- **GDDDT_MOVEGOODS_SGRP**: Форма учета движения товара (по всем складам указазанной группы складов)
- **GDDDT_MOVEQENDORGN**: Остаток товара по указанному поставщику ORGNID - Предприятие EDATE - дата расчета остатка (на конец дня) IORGNID - ID поставщика (ORGN) ALLGOODS - =0 - только по активным товарам, =1 - по всему справо
- **GDDDT_WORKMOVEGOODS**: Форма учета движения Изделий (выпущенных в производстве)
- **GODSLOST**: Служебная процедура - поиск несоответствий в остатках на складе
- **MAINMEAN_AMMOVE**: Движение основных средств за период
- **MAINMEAN_CLCAM1**: Расчет Амортизации/Износа методом уменьшающихся остатков
- **MAINMEAN_MOVE**: Форма учета движения ОС зв период Входные параметры: ORGNID - ID предприятия BDATE - начало отчетного периода EDATE - конец отчетного периода Выходные параметры: ID - Уникальный код записи ОС QNTB - о
- **MAINMEAN_MOVE_DETAIL**: Форма учета движения ОС зв период Входные параметры: ORGNID - ID предприятия BDATE - начало отчетного периода EDATE - конец отчетного периода Выходные параметры: ID - Уникальный код записи ОС QNTB - о
- **MBPMEAN_MOVEGOODS**: Форма учета движения МБП
- **STORZAKAZDT_GDDDT**: Формирование списка товара для расх. накладной по остатку из заказа (резервирование товара) Расх. накладная должна быть пустой (только заголовок DGVDT)
- **STORZAKAZDT_WORKMAINGDS_SEL**: Анализ - Иизделия (по материалам). Выборка материалов для производственного заказа по материалам из складского заказа. Анализ работает с учетом эквивалентов. Входные параметры: SZID - ID складского за
