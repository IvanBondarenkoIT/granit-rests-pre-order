# Чеклист тестирования (gate перед коммитом этапа)

Обязательный минимум **на каждом этапе** — см. `AGENTS.md` §8.

## Общий gate (все этапы)

```powershell
$env:PYTHONPATH="."
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m src.analysis.recommend
```

Сверка **DLSC002** (`product_key=dlsc002`): остаток > 0, `weekly_consumption` ~30–45 шт/нед, `reorder_date` и `recommended_order_qty` без NaN.

При изменении ETL/SQL дополнительно:

```powershell
.\.venv\Scripts\python.exe -m src.etl.run_etl
```

Проверить в SQLite: `products`, `weekly_demand` — строки для 16 критических позиций.
